# 運営スタッフ画面のデザイン

2026-10-18、参加者側の改善に続き、運営ページの改修依頼を受けて実施。

## 対象

`/management` 以下の10ページ：スタッフログイン、大会選択、大会受付、対戦表、各種印刷5ページ、領収書の控え。
管理者専用の `/admin` 以下のページは別の範囲。

## デザイン

- 承認済みのバスケ背景を再利用し、黒・赤・紙の色で参加者側と世界観を揃える。
- 受付パネルは濃色で作業に集中できる面、大会選択と集計は紙の台帳風にする。
- 参加枠内のチームと、メンバー登録が確定したチームを区別して表記。
- 集計は検索の前の全データから算出。キャンセル待ち・辞退は参加枠内の集計から除外する。
- 入金とLINEの確認は色だけに頼らず、文字とボタンの押下状態で示す。
- 対戦表の周囲と、運営専用の外観指定を持つ操作バーを整える。共有コンポーネントの既定の外観と対戦処理は維持する。
- 印刷時は画面用の背景・フッター・案内を隠し、既存の書類本文を保持する。

## 検証

- API呼び出し24箇所、既存の数値演算、領収書本文が変更前と一致することをASTで確認。
- 印刷に使用する共有コンポーネントは未変更。
- テストでログイン失敗時の保持・処理中の操作、料金とキャンセル待ち、検索、LINE確認と入金確認の既存APIを検証。
- 既存の参加者テストも含め、9 suites / 51 tests通過。
- 認証後の画面はAPIモックで検証。実データの入金・LINE確認、対戦結果、削除、印刷等の更新操作は実行しない。
- ブラウザで直接確認できるのは公開のスタッフログイン画面。スマホ実機・認証後画面のブラウザ目視は未実施。

## 受付詳細・対戦操作の仕上げ

- 受付詳細はコートの表紙と明るい受付票。紹介・クリニック・運営メモ・受付確認・印刷や変更操作のまとまりを明示する。
- メモとユニフォーム色の入力は既存のフォーカス離脱時保存を維持。ラベルと入力を関連付け、確認ボタンの状態を読み上げにも伝える。
- 対戦表の明るい紙面、未配置チームのトレー、赤を基調にした保存操作を統一。接続線や試合カードの寸法・勝敗の色分けは維持する。
- 全画面の操作バーは常時読める濃度にし、狭い幅では横スクロール。テーマ・得点表示・カメラ・拡大縮小・閉じる処理はそのまま。
- 共有の `TournamentBracket` と `BracketFullscreen` に任意の `appearance="operations"` を追加。既定は `default`。CSSは運営レイアウトからのみ読み込み、運営指定に限定し、管理者画面は従来の表示を保つ。
- 今回の4つのTSXファイルのAPI呼び出し・イベントコールバック164箇所が、直前の改修済みコードと一致することをASTで確認。
- メモの自動保存、印刷先URL、破壊的操作のキャンセル、通常／運営両外観での勝者確定・保存、全画面テーマ・得点表示・閉じるをモック環境で追加検証。
- 認証後画面とモバイル実機のブラウザ目視は未実施。既存の型エラー10件は今回の対象外。
